# Incident Log

Captures non-trivial failures or risks whose lessons create reusable guardrails.

## Inclusion Criteria
- Failure could plausibly recur.
- Leads to a process, test, hook, or documentation improvement.

## Format
Files: `INC-XXXX-kebab-title.md`
Sections: ID, Date, Status, Context, Symptom, Root Cause, Resolution, Prevention/Guardrail, References, Tags.

See `TEMPLATE.md`.
