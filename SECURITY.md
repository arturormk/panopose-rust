# Security Policy

## Supported Versions

Security fixes are handled on the latest public release line and the current development branch.

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities.

Report security issues through GitHub private vulnerability reporting when it is available for this repository. If it is not available yet, contact the maintainer privately and include:

- affected version or commit;
- operating system;
- steps to reproduce;
- expected and observed impact;
- any relevant files or sample data that can be shared safely.

The project is a local desktop application, but reports involving unsafe file handling, command execution, malicious image metadata, dependency compromise, or packaged installer behavior are in scope.
