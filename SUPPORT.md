# Support

Use GitHub issues for reproducible bugs and focused feature requests.

Before opening an issue:

- check the README for current behavior and known limits;
- include the version shown in the app sidebar or by `panopose --version`;
- include your Linux distribution and install method;
- describe whether `exiftool` is installed when reporting metadata problems.

Do not use public issues for security reports. See [SECURITY.md](SECURITY.md).
